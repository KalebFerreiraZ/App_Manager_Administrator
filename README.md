# App Manager Administrator

App Manager Administrator is a software project under development designed to help administrators manage and consult operational records in one place.

The project includes a web interface connected to a backend API. One of its intended workflows is looking up records by registration number (*matrícula*) and working with related information.

## Project Goals

- Make administrative information easier to access.
- Provide a web interface for interacting with backend services.
- Support record lookup using a registration number.
- Organize and simplify administrative workflows.

## Technologies

- **JavaScript**
- **React** — Frontend
- **Node.js** — Backend runtime
- **Express** — API and routing
- **MongoDB** — Database

## Development Status

This project is currently under development. Features, routes, and the user interface may change as development continues.

## Future Improvements

- Expand administrative features.
- Improve input validation and error handling.
- Enhance the user interface and user experience.
- Add new tools to simplify administrative workflows.
